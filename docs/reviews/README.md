# Review records (legacy)

This directory is a legacy local record from the period when cc-loop pushed directly to `main`. Magpie has no `docs/reviews/`; its records live in PR comments and commit bodies (`docs/code-standards.md`; PR #1339).

From 2026-11-15 the repository uses the maintainer PR flow in `docs/contributors.md`: the record is a PR comment using `pr-review-record.md`, and the merge is at the reviewed head. Do not add new files here; keep the existing ones as history.
