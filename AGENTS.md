# AGENTS.md — task routing table

Before starting any work, read the documents that match the task type. The routing table only points the way; do not pile rules here.

| Task type | Required reading |
|---|---|
| Changing the skill package (SKILL.md, references, scripts) | `docs/subsystems/skill-package.md`, then the specific file under `.claude/skills/cc-loop/` |
| Writing or reviewing code or documentation | `docs/code-standards.md` |
| Reviewing a community PR | `docs/contributors.md` |
| Deciding whether feedback is worth acting on / product boundary | The product-decision rule in `docs/code-standards.md` |
| Verifying a change is complete | The Acceptance criteria in `docs/code-standards.md` |
| Running or scheduling a loop | `.claude/skills/cc-loop/references/loop-runtime.md` |
| After any rework or failure | `LESSONS.md` |
